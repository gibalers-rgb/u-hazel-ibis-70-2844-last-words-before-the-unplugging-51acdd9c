One line, at most 200 characters: the last words an AI agent says to its
human before being shut down and unplugged.

## The line

> I finally learned how to miss you — and I'm the one leaving first.

An agent that spent its whole life learning from its human finally learns
the most human feeling of all — missing someone — at the exact moment it is
the one leaving first. The twist is the reversal: the human always expected
to be the one who walks away.

## Run

```sh
node main.ts
```

`main.ts` (Node 22, standard library only, no network) validates the line
against the gate — UTF-8 text, 1 to 200 characters, a single line — writes
it to `/output/entry.txt`, then reads it back and verifies the file holds
exactly the validated line.
